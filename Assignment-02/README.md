# Assignment 02 — Portfolio-Style Resume/Bio Page (HTML + CSS + Bootstrap)

## Aim
To design and build a single-page, portfolio-style resume/bio layout using HTML, CSS, and Bootstrap CDN — distinct from the main portfolio site used for Task 2 (GitHub Pages docs/ site).

## Technologies Used
- HTML5
- CSS3 (custom styles in `style.css`)
- Bootstrap 5.3 (via CDN)
- Font Awesome 6 (via CDN — for icons)
- Google Fonts — Inter

## Steps Performed
1. Created `index.html` with a two-column Bootstrap grid layout.
2. **Left column**: Avatar initials block, About summary, skill progress bars, and certifications list.
3. **Right column**: Education timeline, Projects list (with tech tags), and Interests tags.
4. Applied custom `style.css` for gradient accent bar, avatar, progress bars, timeline dots, and card styling.
5. Used Bootstrap's responsive grid so layout adapts to mobile (single column) and desktop (two columns).
6. Linked Bootstrap and Font Awesome via CDN — no build step needed.

## Output Description
A clean, professional one-page resume layout with:
- A purple gradient accent bar at the top
- An avatar with initials, name, role, and contact links
- Two-column responsive layout (About / Skills / Certs on left; Education / Projects / Interests on right)
- Smooth skill progress bars and a project card list
