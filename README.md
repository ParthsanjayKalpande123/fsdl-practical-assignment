| **Backend Framework** | Express.js 4.x |

## How to Run

### Static Assignments (01–04)
Open `source-code/index.html` directly in any browser.

### Node.js Assignments (05–06)
```bash
cd Assignment-0X/source-code
npm install
npm start
```

### React + Express Assignments (07–08)
**Terminal 1:**
```bash
cd Assignment-0X/source-code/server
npm install && npm start
```
**Terminal 2:**
```bash
cd Assignment-0X/source-code/client
npm install && npm start
```
