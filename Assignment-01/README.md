# Assignment 01 — HTML Text Formatting Tags Reference Table

## Aim
To create a static HTML web page that lists all standard HTML text-formatting tags in a structured table, displaying each tag's name, description, example code, and live rendered output.

## Technologies Used
- HTML5

## Steps Performed
1. Created a single `index.html` file with a complete HTML5 document structure.
2. Added a styled `<table>` element with four columns: **Tag Name**, **Description**, **Example Code**, and **Rendered Output**.
3. Listed 25 standard HTML text-formatting tags including `<b>`, `<strong>`, `<i>`, `<em>`, `<u>`, `<s>`, `<del>`, `<ins>`, `<mark>`, `<small>`, `<sub>`, `<sup>`, `<code>`, `<pre>`, `<kbd>`, `<samp>`, `<var>`, `<abbr>`, `<cite>`, `<q>`, `<blockquote>`, `<address>`, `<bdo>`, `<time>`, and `<big>`.
4. Each row uses the actual HTML tag to demonstrate the rendered output inline.
5. Applied custom CSS within a `<style>` tag for table styling, hover effects, and colour coding.

## Output Description
A clean, styled HTML page showing a full-width table. Each row represents one HTML text-formatting tag with the rendered output visible directly in the browser. Alternating row colors and hover highlights make it easy to read.
