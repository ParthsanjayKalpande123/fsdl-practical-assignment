HTML Text Formatting Tags

Assignment 01 — Full Stack Development Lab  |  A reference table of all standard HTML text-formatting tags

Tag Name Description Example Code Rendered Output
<b> Bold text — makes text visually bold without semantic meaning. <b>Hello World</b> Hello World
<strong> Important/strong text — bold with semantic importance. <strong>Critical Note</strong> Critical Note
<i> Italic text — renders text in italics without semantic meaning. <i>Italic Text</i> Italic Text
<em> Emphasized text — italic with semantic emphasis meaning. <em>Emphasized</em> Emphasized
<u> Underlined text — adds an underline to the text. <u>Underlined</u> Underlined
<s> Strikethrough — draws a line through the text. <s>Old Price $50</s> Old Price $50
<del> Deleted text — semantic strikethrough (indicates deleted content). <del>Deleted Content</del> Deleted Content
<ins> Inserted text — underlined, indicates newly inserted content. <ins>New Content</ins> New Content
<mark> Highlighted text — applies a yellow highlight background. <mark>Highlighted</mark> Highlighted
<small> Small text — renders text in a smaller font size. <small>Small Print</small> Small Print
<big> Big text — renders text slightly larger (deprecated in HTML5). <big>Big Text</big> Big Text
<sub> Subscript — renders text below the baseline (e.g., chemical formulas). H<sub>2</sub>O H2O
<sup> Superscript — renders text above the baseline (e.g., exponents). x<sup>2</sup> x2
<code> Inline code — displays text in a monospace code font. <code>console.log()</code> console.log()
<pre> Preformatted text — preserves spaces and line breaks. <pre> Hello</pre> 
  Hello
<kbd> Keyboard input — denotes text typed on a keyboard. <kbd>Ctrl+C</kbd> Ctrl+C
<samp> Sample output — represents output from a computer program. <samp>Error 404</samp> Error 404
<var> Variable — denotes a mathematical or programming variable. <var>x = y + 1</var> x = y + 1
<abbr> Abbreviation — shows the full form on hover via title attribute. <abbr title="HyperText">HTML</abbr> HTML
<cite> Citation — marks the title of a referenced creative work. <cite>The Great Gatsby</cite> The Great Gatsby
<q> Inline quotation — wraps short inline quotations with quote marks. <q>To be or not to be</q> To be or not to be
<blockquote> Block quotation — a longer quoted section, indented by default. <blockquote>Long quote…</blockquote>
Long quoted text here…
<address> Address — contact information for the author/owner. <address>Pune, India</address>
Pune, India
<bdo> Bidirectional Override — overrides text direction. <bdo dir="rtl">Hello</bdo> Hello
<time> Time — marks a specific time or date, machine-readable. <time datetime="2024-01-01">Jan 1</time> Jan 1
